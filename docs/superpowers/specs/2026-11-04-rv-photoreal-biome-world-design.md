# 房车世界：连续生物群系 · 照片级地表与植被（设计）

日期：2026-11-04
项目：`projects/rv`（Nomad Caravan / 末路房车）
状态：待评审

## 1. 意图

把现在「288 m 固定草地高度场 + 外围平地 + 低模占位」的房车世界，升级为**一张连续、可一直开下去的自然世界**：草原、针叶林、雪山、干旱荒原各自成片又自然过渡，地表与植被达到 3A 级照片观感（近景真实、远景可信、无接缝）。

保留现有玩法循环不变：车库改装、驾驶、停靠搜刮、夜袭、联机协作。视觉升级不能以破坏这些为代价。

为什么现在做：世界已经是「一辆车 + 一条无限路」的结构，但视觉资产停留在地形色块 + 程序化低模草阶段，开出去 288 m 就是平地，区域之间没有任何差别。继续加 POI 只会让「世界感」的短板更明显。

## 2. 目标 / 非目标 / 反目标

### 目标
- **连续世界**：任意方向可一直开，无加载屏、无地形接缝、无可见 LOD 跳变。
- **生物群系**：温带草原、针叶林、高山雪原、干旱荒原；每个群系有独立的地表材质组合、植被组合、天气/雾/色调。过渡带宽 40–120 m，权重平滑混合，不出现硬边。
- **照片级地表**：4 层 PBR 混合（albedo + normal + roughness + AO），双尺度宏观变化抑制平铺，陡坡三平面投影消除拉伸；雪层独立且随海拔/坡度/遮挡变化。
- **照片级植被**：密集 GPU 草（成簇、风摆、近密远疏）、树木 3 级 LOD + 远景 impostor、灌木/野花/岩石按群系密度分布；雪线以上切换为雪松/枯树/雪岩。
- **雪山**：海拔驱动的雪线、雪面微光、雪被天气动态覆盖；远山有体积感（雾+大气透视），不是一张白色贴图。
- **替换方块**：主要 POI 建筑与大型道具改用作者级模型（Blender 管线），不再用盒子拼。
- **可验收**：每一批都有截图对比、确定性测试和帧率记录。

### 非目标
- 不改玩法数值、UI 布局、联机协议语义。
- 不做可破坏/可挖掘地形。
- 不做硬件光追（保留为后续可选项）。
- 不重做房车车体与室内（本轮只做世界）。

### 反目标（即使「技术完成」也算失败）
- 群系只是换配色：地形起伏、植被种类、天空雾色都一个样。
- 近景为了远景让路：站在车旁能看到贴图平铺、LOD 跳变、草地稀成斑块。
- 为了好看把玩法弄坏：道路被地形穿透、POI 悬空、驾驶手感变化、存档失效。

## 3. 约束

- 引擎：Vulkan，已有 CSM、SSAO、SSR、体积雾、Bloom、TAA、自动曝光、IBL/光照探针、GPU 实例化、`windSway`、地形 LOD 网格工具。
- 逻辑：游戏玩法在 Lua（`projects/rv/assets/scripts/lc/*`）。**世界生成与地形渲染必须下沉到引擎 C++**——Lua 每帧生成/管理上千个 chunk 不现实。Lua 只做查询（`GetGroundHeight`）与状态。
- 确定性：同一世界 seed + 同一份「世界要素清单」必须生成同样的地形。地形不是纯 `(x,z,seed)` 函数——道路、POI、营地是显式要素，会作为压平遮罩参与生成。
- 现有存档兼容：老档的房车位置、布局、POI 仍能加载；但**不承诺旧地形形状完全不变**，老档会在新地形上重新落地（见 §4.6）。
- 目标硬件：高端独显（当前开发机是核显，不作为性能基线）。
- 资产许可：外部扫描材质/模型必须是可商用、可再分发（CC0 优先），且要落进仓库。
- 后端：新地形/植被管线以 **OpenGL**（当前默认后端，`NEON_ENABLE_VULKAN=OFF`）为验收路径；shader 源保持可被 Vulkan 管线转换，但不要求 P1 双后端同步（见 §4.7）。

## 4. 技术方案

### 4.1 世界与生物群系（新增引擎模块 `neon::world`）

**坐标系**：世界坐标无限，单位米，Y 向上。所有生成函数是 `(x, z, seed)` 的纯函数，客户端/服务端/联机代理用同一套。

**气候场**（低频、确定性）：
- `elevation(x,z)` = fBm（4–6 octave）+ ridged noise 叠加。ridged 只在「山地遮罩」内生效。
- `temperature(x,z)` = 纬度趋势 + 海拔递减 + 低频噪声。
- `moisture(x,z)` = 低频噪声 + 河流/湖泊遮罩。
- `biomeWeight` 由 (temperature, moisture, elevation) 得到 4 个平滑权重，归一化后存进地形顶点与植被分布图。

**生物群系布局**（以现有营地/道路图为锚）：
- 营地与 0–300 m：温带草原（现有内容全部落在这里）。
- 西侧：针叶林带。
- 东侧：干旱荒原/雅丹。
- 北侧 400 m 外：海拔抬升进入高山雪原，新增 3 个远端 POI（滑雪场/气象站/废弃隧道）。
- 西侧针叶林新增 2 个远端 POI（林场/护林站扩建）；东侧荒原新增 1 个（矿场）。
- 道路从现有 z≈220 m 的尽头继续向北延伸，用样条连接雪原与林场 POI；新道路同样参与地形压平。
- 群系边界由气候场决定，不写死圆形区域；道路与 POI 的压平遮罩优先级最高。

**地形高度**：`height(x,z) = biomeBlend(各群系地形函数)`。草原=缓丘，森林=起伏+沟谷，荒原=台地+冲沟，雪山=陡峭山脊。所有高度都经过道路/POI/营地压平。

**世界要素清单（feature list）**：地形模块持有显式要素列表——固定节点图、道路样条、已存档 POI、运行时新增 POI。压平遮罩来自这份清单，`AddPad/RemovePad` 会使受影响 chunk 重建。这取代「纯函数」：同 seed + 同清单 = 同地形。

**道路**：保留现有节点图与坐标，改为「样条 + 宽度 + 路肩」生成；地形沿路廊道压平并生成路基横断面，避免地形穿路。运行时新增 POI 会先向地形注册场地，再落地建筑，避免悬空。

### 4.2 地形渲染（引擎新增，替换烘焙 glTF）

- **Chunk + 环形 LOD**：32 m chunk，四叉树/环形 5 级 LOD，裙边遮缝；视距 1.5–2 km，更远由雾与天空接管。每帧按相机位置流式加载/卸载，驻留预算固定。
- **顶点数据**：位置、法线、生物群系权重（4 通道）、坡度/高度派生量、世界 UV（三平面用）。
- **材质**：扩展 `lit_terrain` 变体为 **8 层 PBR 纹理数组**（草地/泥土/岩石/雪/林下腐殖/砂砾/荒原硬土/崖壁），每层 albedo + normal + roughness/AO 打包进 `sampler2DArray`，用索引采样；避免 Sampler 槽位上限与每群系重复绑定。
  - 群系身份由「层组合 + 权重 + 色调」共同决定，不是只换 tint；
  - 高度混合（height-based blend）避免层间线性糊；
  - 双尺度 macro variation（大尺度色斑 + 细节噪声）打散平铺；
  - 坡度 > 阈值的区域三平面投影；
  - 雪层：独立权重，叠加雪面高光与微光噪声。
- **细节**：近景 1 m 网格 + 细节法线；远景法线渐隐，避免闪烁。
- **阴影**：地形自身接收 CSM，不投射；山体大尺度自阴影用烘焙的 horizon/AO 项近似。

### 4.3 植被与岩石

- **草**：GPU 实例化草簇（每簇 3–6 个交叉卡片），按群系密度图 + 坡度 + 距相机距离分布；风摆复用 `windSway` 并加入阵风波纹；近处 60–120 m 实体，远处过渡到地表材质里的「草色噪声」，不做 billboard 闪烁。
- **树**：每树种 3 级 LOD + 远景 impostor；针叶/阔叶/枯树/雪松按群系与海拔分布；树干、树冠分开实例化。
- **灌木/野花/岩石**：实例化 + 规则分布（坡脚多石、林下多蕨、荒原多砾石）；岩石使用三平面材质。
- **交互**：车轮与玩家压草（可选，放到最后一批）。
- **碰撞预算**：只有相机/房车约 120 m 内的树与岩石生成流式 Jolt 静态体；远处森林是纯视觉，不参与碰撞。这是有意的玩法取舍（否则 2 km 森林会拖垮物理），需要在验收里明确「远处树木可穿过」。

### 4.4 光照、大气与雪

- 保留 CSM/SSAO/SSR/体积雾；新增**高度雾**与太阳散射，使远山有层次；群系切换时插值雾色/密度/天空色调。
- 时间-of-day 已有基础，补一套按群系微调的曝光曲线，避免雪地过曝。
- **积雪**：`snowMask = f(海拔, 坡度, 朝向, 天气积累)`；降雪时低海拔也短暂积雪，晴天缓慢消退。雪面 roughness 更低、带高频闪光。

### 4.4a 水体（真实水面）

- 湿度场里的河流/湖泊遮罩同时驱动**真实水体**：地形在河道/湖盆处下切，水面用引擎现有 water 材质（程序化波法线 + Fresnel + 平面反射 + 折射 + 岸边泡沫）。
- 水面是流式 chunk，跟随地形 LOD；湖面/河面保持同一水位，岸边用湿沙/卵石层过渡。
- 车辆入水按深度降速/熄火风险，取水接口复用现有 pond 逻辑；联机同步水位与水面状态。

### 4.4b 陡坡驾驶（玩法联动）

现有房车是四点弹簧采样高度，俯仰/侧倾夹在 ±20°，没有侧向地面碰撞，理论上能开上近垂直山壁。新世界有陡峭山脊，因此 P1 起加入**坡度牵引**：坡度 > ~25° 开始掉速、> ~35° 明显打滑/下滑，> ~45° 视为不可通行（视觉上仍是山体，不设隐形墙，靠物理劝退）。道路与 POI 通路保证在可驾驶坡度内；越野翻山允许但代价明显。这是本轮唯一有意改动的驾驶手感，需在验收里单独确认。

### 4.5 资产管线

- **地表材质**：使用 CC0 扫描材质（Poly Haven / ambientCG），**一律 2K，以 PNG 压缩入库**（albedo / normal / packed rough+AO），落盘到 `projects/rv/assets/textures/terrain/<layer>/`；GPU 侧用 `sampler2DArray` 按层上传。BC7/BC5 作为后续显存优化项，P1 不做（当前 GL 只原生支持 DXT1）。程序化材质只作为兜底与混合层。
- **建筑/大型道具**：Blender MCP（`tools/start_blender_mcp.py`）作者级建模，沿用 roadhouse / ranger tower 的产出流程；每个资产带 LOD 与碰撞体。
- **树木**：Blender 生成或 CC0 资产，统一到同一材质/风摆规范。

### 4.6 玩法与存档

- 世界 seed 写入存档（v6）；老档无 seed 时使用固定默认 seed。
- POI、道路、营地位置仍由节点图决定（不随 seed 漂移），seed 只影响群系/地形细节。
- **老档迁移**：保留房车坐标、POI 编号、建筑布局；地形形状会变，因此加载时对房车/POI/道具做一次「重新落地」（按新 `GetGroundHeight` 抬到地面），并记录迁移事件。营地核心区仍保持接近 0 的平地，避免整片建筑位移。
- 当前 POI 是 `math.random()` 在「低地」挑选后写入存档的；新地形下低地不再普遍，改为「节点图固定位置 + 场地压平」，避免每次开图位置漂移，联机也更容易对齐。
- `GetGroundHeight` 改为查询新地形系统；Lua 侧所有采样点保持同一套 API，避免大改。

### 4.7 后端策略

- 新地形、草、树管线以 **OpenGL** 为验收后端（当前构建默认 `NEON_ENABLE_VULKAN=OFF`，且 GL 已支持所需的 texture array / instancing）。
- shader 源继续放在 `builtin_shaders.hpp`，保持 `gen_gl_shaders.ps1` 的 Vulkan 兼容写法；Vulkan 版本等后端开启后再补，不作为 P1 验收条件。
- 这样避免为了后端开关先做一轮 SDK/SPIR-V 工具链改造，P1 能立刻用截图验收。

## 5. 分期

| 批次 | 内容 | 可见结果 |
|---|---|---|
| P1 | 引擎地形系统 + 群系高度/材质 + 道路压平/延伸 + 远端 POI 场地 + 现有内容重新落地 | 能连续开出去，草原→森林→雪山有明显变化，地表不再是色块，雪原有目的地 |
| P2 | 草/树/岩石实例化 + LOD/impostor | 近景植被密度和风摆到位，远景不闪 |
| P3 | 光照/高度雾/雪线/天气 + 真实水体 + 岸边 | 雪山、湖面、黄昏/阴天有照片感 |
| P4 | POI 建筑替换（按体积排序） | 加油站/商场/仓库/诊所等不再像盒子 |
| P5 | 打磨、性能、验收、存档迁移 | 全流程截图与测试通过 |

每批独立可验收；P1 完成前不动 POI 模型，避免两套世界坐标打架。

## 6. 验收

- **连续性**：从营地沿任意方向开 2 km，无接缝、无空洞、无穿模；地形高度与物理/玩家采样一致。
- **群系**：4 个群系在 1 km 内可遇到；过渡带无硬边；每个群系的植被/地表/雾色组合不同。
- **地表**：近景 5 m 内可见法线与细节层；无肉眼可见平铺（同屏重复率检查）。
- **雪山**：雪线随海拔变化；降雪后低处有薄雪；雪面不过曝。
- **LOD**：相机快速移动时无跳变/裂缝；远景 impostor 与实体树过渡自然。
- **性能**：高端独显 1080p 60 fps 为目标（记录 GPU 帧时间）。
- **回归**：现有自测（`lc_selftest`）、存档读写、联机代理、驾驶手感通过。

## 7. 留给构建者的决定

- chunk 尺寸、LOD 级数、视距的具体数值（按实测调整）。
- 草簇的几何形态与密度曲线（近/远阈值）。
- 各群系材质的具体贴图组合与混合参数。
- 树木/岩石的 LOD 切换距离。
- 雪面微光/闪光的具体实现。
- 新旧存档迁移的默认 seed 取值。

## 8. 已确认的决策

1. **外部 CC0 扫描材质**：允许；统一 2K，压缩格式入库（BC7/BC5/BC4），源 PNG 不入库。
2. **远端 POI 与道路**：P1 一起做——雪原 3 个、林场 2 个、荒原矿场 1 个，道路从 z≈220 m 向北延伸并连接。
3. **水体**：做真实水面（现有 water 材质），P3 与光照/天气一起交付；P1 先做河道/湖盆下切。
4. P4 建筑替换优先名单在进入 P4 前再定。
