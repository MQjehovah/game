# Last Caravan（末路房车）— 设计文档 v0.1

末世题材房车改装游戏。工作名 Last Caravan，工程目录 `projects/rv`。

## 一句话

把一辆破房车改成你的移动堡垒：**网格化布局 + 四大资源网（电力/水/载重/舒适）**，
前期做车库改装沙盒（纯沙盒先行），后期包上"旅途经营 + 停靠劫掠"的生存外壳。

## 已定方向（用户拍板）

| 决策 | 选择 |
|---|---|
| 呈现视角 | 由实现定 → **3D 斜俯视**（MOBA 式相机，引擎管线最成熟，布局操作最直观） |
| 核心循环 | **纯改装沙盒先行**——先不做生存压力，把"布局-供电-水路-舒适-载重"做深做爽 |
| 改装粒度 | **网格模块化**——车厢划网格，模块吸附格子放置、可旋转，布局决定属性 |

## 核心循环（终态愿景，沙盒阶段只做中间一层）

```
世界地图选路线（油/风险） ──► 停靠点下车搜刮（限时/遇袭）
        ▲                              │
        │                        物资/材料入库
        │                              ▼
   随机事件/袭击 ◄── 上路 ◄── 车库改装布局（本项目的"肉"）
```

沙盒阶段 = 上面中间那一块：**车库模式**。无时间压力，专注改装手感与系统深度。

## 车体与网格（v0.1 实装参数）

- 单元格 **0.5m**。车厢内部网格 **4 × 14 格**（2.0m 宽 × 7.0m 长，56 格）。
- 车头驾驶区不参与布局；车库视角**无车顶**（俯视改装是类型惯例）。
- 网格原点/尺寸只在一处定义（Lua `GRID` 表），存档记录格子坐标，改车体不破档。

## 模块 schema（数据驱动，后续迁 JSON 数据表）

```lua
{
  id = "bed_double", name = "双人床",
  w = 3, h = 4,              -- 占格（可旋转互换）
  color = "#8A5A44",
  powerDraw = 0, powerGen = 0,   -- kW
  waterDraw = 0, waterStore = 0, -- L/h, L
  weight = 60,                   -- kg
  comfort = 30,                  -- 舒适度点数
  tag = "basic",                 -- 后续：解锁条件/分类
}
```

v0.1 目录（10 件）：双人床、单人床、灶台、冰箱、净水箱、电池组、太阳能板（车内
简化放置）、工作台、储物箱、电暖器、娱乐柜、炮塔底座（预留，无功能）。

## 四大资源网（v0.1 结算规则，模块即属性）

| 资源 | 计算 | 失衡表现 |
|---|---|---|
| 电力 | 发电(solar) − 用电(stove/fridge/heater/tv)，电池=缓冲 | 余量为负 → 面板飘红 |
| 水 | 净水箱储量 − 用水(灶台等) | 余量为负 → 飘红 |
| 载重 | Σ模块重量 vs 底盘 1500kg | 超载 → 飘红（未来：油耗↑/速度↓） |
| 舒适度 | Σ舒适点数 / 100 → % | 纯展示（未来：士气/休息效率） |

**布局的深度来自约束**（后续版本逐条加入）：走道连通性（床够不着=睡不了）、
噪音/气味（冰箱不能贴床）、灶台必须靠水箱一侧的管线墙、太阳能板实际只能上车顶
（独立车顶层）、电池/水箱的供 能/水 管线长度惩罚。

## 操作（沙盒 v0.1）

- 数字键 1..9/0 或点击底部热栏：选择模块
- 鼠标移动：幽灵预览（绿=可放，红=冲突/越界）
- 左键放置；R 旋转；悬停 + X（或右键）拆除；G 开关网格显示
- F5 保存布局 / F9 读取（`WriteText/ReadText` → `saves/layout.json`）

## 技术映射（引擎现成能力 → 用途）

| 引擎能力 | 用途 |
|---|---|
| 3D 管线（PBR/CSM/后处理，刚做过全面体检） | 车库场景、车体、模块几何 |
| `Spawn` + `SetEntityComponent("mesh",…)`（反射组件） | 模块实例 = 彩色盒子（占位几何） |
| `PickGround` / `InputMouse*` / `InputKey` / `MouseWheel` | 拾取格子、放置交互 |
| `SpawnDecal` + 网格贴图 | 地面网格高亮/格线 |
| `DrawRect/DrawText/DrawGroundRing` | 统计面板、热栏、幽灵 footprint |
| `ReadText/WriteText` | 布局存读档（`saves/layout.json`） |
| `LoadDataTable` + JSON | 模块目录数据驱动化（P1） |
| glTF 加载 / Kenney 资产管线（已有先例） | 模块真模型（P1：用带贴图 GLB 替换色块） |
| **坑 1**：运行时可见实体必须走 `SpawnPrefab`（assets/prefabs/*.json）——`Spawn`+`SetEntityComponent` 只写 SceneData JSON，不会物化成 `SceneMesh`，DrawSystem 只扫 SceneMesh，因此**画不出来** | 模块/幽灵/网格线全部预制体化（16 个） |
| **坑 2**：HUD 必须写在全局 **`on_render()`** 里——`DrawRect/DrawText` 的 draw2d 上下文只在渲染期接线，on_update 里画图静默丢弃；on_update 只做模拟/状态 | 车库 HUD（面板/热栏/提示） |
| **坑 3**：贴花组件 size 与实体 SetScale 是**叠乘**关系——标准用法 = `SpawnDecal(size=1.0)` + `SetScale` 控制长宽/高度（同 moba spawnGroundQuad）；size 传非 1 再 SetScale 会把贴花放大 size 倍 | 网格贴花（已按标准用法） |
| **坑 4**：`Spawn`+`SetEntityComponent` 创建的实体**不渲染**（见坑 1 的根因），运行时可见物一律 SpawnPrefab | 全部网格/幽灵/贴花 |
| Jolt 物理（PhysicsAdd*） | P2 车辆驾驶/物理化 |
| NavGrid / NavBlock | P2 走道连通性判定 |
| 昼夜天空 / 体积光 / 天气 | P2 旅途氛围 |

## 驾驶模式（P2.5 实装：T 上路 / 空格停靠）

房车在荒漠里真的开起来。纯 Lua 实现，引擎零改动。

- **进入/退出**：车库模式按 `T` 上路；驾驶中 `空格` 停车——回到车库模式，
  可在任意荒野位置继续改装。
- **驾驶模型**（简化物理，未上 Jolt）：W 油门 / S 刹车+倒车 / A·D 转向。
  转向速率与速度挂钩（3 m/s 打满、静止转不动、倒车反向），滑行有阻力。
  **超载联动**：载重超 1500kg 后极速/加速按超出比例打折（速度表数字与载重条变红）。
- **无限荒漠**：地面方块放大到 800×800 并跟随房车（纯色材质，无接缝无边缘）；
  88 个荒漠道具（灌木×2 / 岩石 / 枯树 / 残骸，6 个新 prefab）出视野
  （车后 40m / 横向 55m）即回收，在车前 25..70m 重生；正前方 5m 与节点 10m 内留空。
- **世界节点**：worldmap.json 的 6 节点获得世界坐标（营地=原点，地图 1.0 ≈ 160m），
  每节点立黄色标记柱（营地除外——柱子会插在房车里）；12m 内空格停靠即记为
  当前停靠点并写入存档。名字牌用 `WorldToScreen` 投影在 on_render 绘制
  （引擎 `SetEntityPlate` 只是数据 API，不主动渲染）。
- **相机**：车库=场景原始机位（锚定房车）；驾驶=车后追逐（指数平滑 + 高速微震）。
  两态共用一套 `updateCamera`，模式切换自带运镜过渡。
- **位姿整体变换**：车体 10 个部件、全部模块、网格贴花都记录**房车局部**坐标
  （`spawnModule` 返回 ox/ly/oz/lrot 供 place 记账），`applyRvTransform()` 用
  R(yaw) 统一摆放；`worldToCell` 做逆旋转——房车停在任何位置/朝向都能继续放置。
- **存档 v3**：`layout.json` 增加 `rv = {x, z, yaw, node}`（旧档无此字段 = 原点）。
- **验证钩子**：scriptBaseDir 下放 `autopilot_on.txt` 即自动上路巡航 16s 后停回
  车库（Lua 沙箱无 os 库，读不了环境变量）；配合 `neon_game --screenshot` 逐帧
  验收（行驶 / 停车回路 / 节点名牌三态均有实机截图）。

## 风险与取舍

- 模块占位色块先于真模型：**系统正确性优先**，几何后换（引擎 glTF 管线成熟，风险低）。
- 网格 0.5m 对"床上翻身/过道宽度"这类细节偏粗：P1 若需要可局部加密到 0.25m（只动 GRID 表）。
- 车内视角（第一/三人称）与斜俯视并存：编辑用斜俯视，P3 可加"参观模式"。
